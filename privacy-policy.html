Privacy Policy

Last updated: May 5, 2026

Overview

Ultimate Clipboard Pro is designed to help users capture, organize, search and reuse clipboard-related content inside their browser. This policy explains what data the extension handles and how it is used.

Data The Extension Handles

The extension may handle the following data when users choose to capture or manage it:

  • Copied or selected text.
  • Captured images and screenshots.
  • Detected code snippets.
  • Source URLs and page titles, when available, to support reverse search and reopening the source page.
  • Categories, subcategories, favorites, pinned items, notes, trash state and extension settings.
  • Backup and restore metadata.

Local Storage

Copied text and images are stored locally in the user's browser for normal extension use. Categories, favorites, pinned items, notes and settings are also stored locally using browser extension storage.

Server Transmission

For normal extension use, copied text and images are not sent to our servers. The extension does not sell, rent or trade user clipboard data.

Optional Cloud Backup

If the user enables an optional cloud backup feature, backup data may be stored in the user's own connected account. This feature requires explicit user authorization and can be disabled by the user.

Dodo Payments

License and payment data may be handled by Dodo Payments when a user purchases a Pro license. Copied text, captured images and clipboard content are not sent to Dodo Payments.

No Sale Of User Data

We do not sell user data. We do not sell copied content, captured images, browsing source URLs, categories, notes or settings.

Deleting Local Data

Users can delete local data from inside the extension by removing individual items, emptying Trash, clearing extension data, or removing the extension from Chrome. Users can also delete optional cloud backup files directly from their own connected cloud account.
